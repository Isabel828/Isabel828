Aplicação de ponto de venda desenvolvida em Python para registrar compras, validar dados de entrada e calcular descontos conforme regras de negócio.

**Principais funcionalidades:**
- Aplicação sequencial de descontos
- Validação de valores e idades
- Registro de múltiplas compras
- Consolidação de valores e descontos
- Testes de execução documentados
